# Personal Mission Reflection

Understanding cloud infrastructure before deployment is fundamental to engineering reliable, secure, and cost-effective systems. Among the key components—compute, storage, networking, and identity management—networking stands out as the most critical backbone. Without a well-designed network, individual compute and storage resources cannot communicate, and end users cannot securely reach hosted applications.

Linux serves as the cornerstone of modern cloud computing. Most public cloud instances, container engines, and serverless architectures run on Linux kernels due to their security, performance efficiency, open-source adaptability, and robust Command Line Interface (CLI). Learning Linux system commands empowers engineers to automate tasks, inspect server health, and troubleshoot workloads effectively.

Developing comprehensive technical documentation prior to infrastructure deployment prevents architectural misconfigurations, reduces unnecessary cloud expenses, and ensures alignment across engineering teams. Clear documentation serves as a single source of truth for security compliance, scaling strategy, and disaster recovery planning.

Through this activity, I gained practical skills in evaluating virtualized Linux hardware specs, identifying equivalent services across AWS, Azure, and GCP, and mapping system components into cloud infrastructure diagrams. Additionally, structuring this work inside my GitHub portfolio reinforced professional version control workflows and documentation standards.
